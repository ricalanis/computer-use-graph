Does a self-explored site graph beat flat memory — at equal cost?

A public, clean-room research project. The question, the evidence base behind it, and the experiment we built to answer it.

The bet. An agent that explores a website on its own and builds a type-abstracted graph of it — pages as nodes, affordances as edges — beats an agent that rereads flat transcripts, when both get the same memory budget and the exploration cost is counted.

The evidence base. Six research threads, 176 sources, every load-bearing claim re-verified by the root session (✓ marks). Twenty findings changed the plan. Two matter most here:

  • F1 — the closest paper (Environment Maps, arXiv:2603.23610) already ran graph-vs-none on WebArena: 14.2 → 23.3 → 28.2. So our novelty is autonomous exploration, a held-out firewall, and amortized cost.
  • F2 — wherever a flat baseline existed, flat memory took ~2/3 of the win. The real fight is graph vs flat, and it will be small.

computer-use-graph02 / 05 · experiment

The miniature: same data, two memories, one difference

A controlled replica of the Environment Maps arm structure, on a synthetic admin panel — with the two controls their setup lacked.

The site. 25 pages, 3-level navigation, decoy labels: “Email digest” next to “Email notifications”, “Install analytics” next to “Install beta analytics”. The agent gets no hints about which is real. Validators credit only real effects.

The firewall. A task-agnostic random walk explores the site — it never sees task text. Every evaluation task is held out by construction. The same exploration log builds both memories.

The arms. none / flat (recency-ordered transcript) / graph (typed pages, affordance→destination edges). Char-matched budgets. Identical information — the only difference is structure.

What this is not. Not evidence for the hypothesis — a smoke test of the machinery, powered to reproduce the literature’s warnings, not to detect the effect. The pre-registered plan for the real experiment is in the repo (docs/02-design-v0.2.md).

Read it honestly. The ordering (none < flat < graph) matches the hypothesis and the prior work. The primary contrast is +2.8pp and not significant — which is the expected result at n=72: our own power tables said this sample cannot resolve a small effect. The flat-dominance finding reproduced (79% vs the literature’s ~65%). And the agent’s own confidence is worthless — reproducing Last Step Matters before spending a dollar on the real benchmark.

computer-use-graph05 / 05 · conclusion & next steps

The machinery is validated. The next dollar goes to the real thing.

What the miniature established.

  • The full mechanism works end-to-end: task-agnostic exploration → same-data graph/flat memories → matched budgets → programmatic validators → paired statistics.
  • The literature’s two warnings reproduced live: flat takes most of the win, and verbalized confidence is uninformative.
  • The power math is empirical now — ψ measured, sample size for the real run computed from it, not guessed.

What it did not establish. Whether the graph beats flat. That needs the 362-task benchmark, and the plan is already pre-registered.
